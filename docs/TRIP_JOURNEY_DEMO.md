# Coordinated Trip Journey Demo

This prototype adds two governed planned-route journey demonstrations:

- Commuter participant: coordination confirmed → meet at Access Point → route in progress → arriving → arrived → complete.
- Planned EV/hybrid route participant: route confirmed → Access Point arrival → begin planned route → route in progress → destination arrival → complete.

## Product-state guardrails

- Demonstration only; no live dispatch.
- No guaranteed transportation.
- No real-time vehicle tracking.
- Access Points are public-area coordination previews subject to program review.
- Green Route Credits are promotional/program benefits and are not cash, fares, wages, or guaranteed payments.
- Report-an-issue action displays a prototype support note and does not submit an actual report.
