# Pandera Validation Scope

This branch is limited to canonical commuter CSV validation for the institutional vertical slice.

It may add Pandera/pandas dependencies, a dedicated schema/normalization module, ingestion delegation, tests, and branch-scoped CI evidence.

It must not change Django models, migrations, Core Engine scoring semantics, H3/geospatial behavior, routing, UI, Charging Intelligence, payment behavior, or product-state claims.
